# JavaScript Practice 2 – Mouse Move Animation

This project demonstrates how to create smooth, interactive animations using **JavaScript** and **GSAP** based on mouse movement.

## 🚀 Features
- Real-time mouse tracking
- Smooth horizontal movement using GSAP
- Responsive mapping with `gsap.utils.mapRange()`

## 🛠️ Tech Stack
- HTML
- CSS
- JavaScript
- GSAP (GreenSock Animation Platform)
